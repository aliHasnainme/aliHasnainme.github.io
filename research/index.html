Research & Projects

My primary research focuses on making multi-agent LLM systems reliable and practical. In complex tasks requiring many conversational turns or asynchronous steps, models often suffer from lost state, erratic execution, and malformed outputs. Below are details of the projects I have developed to address these problems.

Validator-AI: A Stateful Multi-Agent System for Automated Startup Validation

Individual Project • University of Sahiwal (2025–2026)

This project investigates founder assistance during the startup validation process. Initially, the system was implemented as a stateless request-response workflow. In multi-turn evaluations, this caused severe context loss, repetitive questioning, and inability to handle process disruptions.

State Persistence via PostgreSQL Checkpointing

To solve context loss, I redesigned the pipeline into a state graph using LangGraph backed by a PostgreSQL state checkpointer. Each decision node updates a shared state object that is committed to the database after execution. If an API rate limit, network disruption, or server restart occurs, the workflow can resume from its last valid checkpoint without restarting from the beginning.

Self-Healing Schema Validation

When agents output structured recommendations, downstream modules require strict JSON schema conformance. To prevent pipeline breaks:

  • Built an automatic self-healing step that catches malformed outputs (missing fields, syntax errors, type mismatches).
  • Re-routes the malformed payload with error context to an automated repair routine before passing state to subsequent nodes.
  • In test evaluations, this caught 100% of the malformed output error patterns defined in the test suite.

Concurrency & Latency Improvements

  • Asynchronous Scheduling: Parallelized independent evaluation tasks (e.g., market sizing, competitor analysis, unit economics) using Python's asyncio.gather, reducing total run time from ~20 minutes to less than 3 minutes.
  • Load Testing: Developed test suites using Pytest, Playwright, and Coverage.py, and ran load tests simulating up to 100 concurrent users to verify state stability under load.

Smart Healthcare Diagnosis System

Personal Project • PyTorch, Transformers

Trained deep learning classification models for radiographic analysis:

  • MRI Brain Tumor Detection: Localizing intracranial lesions using preprocessed magnetic resonance imaging sequences.
  • Chest X-Ray Pathology: Multi-class classification of pulmonary conditions on radiographic images.
  • Achieved 94% classification accuracy on the held-out test split.

Text-to-3D Generation & Geospatial Search

Engineering Role • AI 3D Scanning Solution (2025–Present)

Developed production AI pipelines combining generative modeling and spatial retrieval:

  • 3D Generation: Pipeline using open-source models to generate textured 3D assets from an input image prompt and reference views.
  • Conversational RAG: Grounded user dialogue assistant using LangChain and LangGraph for context retrieval.
  • Spatial Semantic Search: Integrated Google Gemini embeddings stored in PostgreSQL pgvector, filtering search results using the Haversine formula to return nearby items matching semantic queries.
  • Backend Service: Asynchronous FastAPI service with SQLAlchemy ORM and containerized Docker orchestration.
