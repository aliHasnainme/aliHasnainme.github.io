Research & Projects

My research and engineering work centers on making multi-agent LLM systems reliable and practical. In complex tasks requiring many conversational turns, multiple tools, or asynchronous sub-tasks, models often run into real-world hurdles: dropped context, schema parsing errors, and conflicting assumptions between agents. Below are details of the systems I've built to tackle these problems.

Validator AI: Multi-Agent Startup Validation Platform

Bachelor's Final Year Project & Thesis • University of Sahiwal (2025–2026) • aliHasnainme/validator-ai

Validator AI was my undergraduate capstone project and bachelor's thesis. Evaluating a new startup idea thoroughly requires examining multiple angles: market demand, financial viability, tech stack feasibility, competitors, and potential legal hurdles. Doing this manually takes days of research, but giving the entire task to a single LLM prompt leads to hallucinated data and shallow answers. Validator AI explores how a team of specialized agents—each focused on one specific domain—can collaborate to produce a rigorous, structured validation report.

How the Multi-Agent Pipeline Works

  1. Adaptive Founder Interview: An interviewer agent asks 1–5 clarifying questions to unpack the founder's core thesis, target audience, and business model before analysis begins.
  2. Live Web Research: A researcher agent queries the Tavily API to gather live market data, recent competitors, and industry benchmarks.
  3. Concurrent Domain Analysis: Up to 10 specialized agent modules run in parallel:
    • Market Size & Opportunity • Financial Projections • Technical Architecture • Competitor Analysis
    • Business Model Canvas (BMC) • Regulatory Compliance • Go-to-Market Strategy
    • Risk Assessment • Product Roadmap • Funding & Pitch Strategy
  4. Contradiction Resolution & Compilation: Because agents analyze independently, they can occasionally make conflicting assumptions (e.g., market size assuming an enterprise model while the financial module projects consumer margins). A Compiler agent inspects cross-module outputs, resolves discrepancies, and harmonizes the findings.
  5. Report Generation: Formats the finalized data into interactive HTML and JSON reports complete with structured domain scores, viability metrics, and actionable recommendations.

System Architecture & Reliability Engineering

  • Stateful Graph (LangGraph): The system is modeled as a cyclic state graph with a shared blackboard state (ValidationState).
  • State Checkpointing (PostgreSQL): Because full evaluations take a couple of minutes, I integrated PostgreSQL checkpointing so workflows can be safely paused, inspected, and resumed at any step without losing progress.
  • Self-Healing Output Parser: LLMs frequently introduce subtle syntax errors or markdown wrapping when asked for complex JSON. To avoid pipeline failures, I built a progressive recovery fallback: strict Pydantic parsing → regex JSON block extraction → brace balance repair → syntax correction.
  • Asynchronous Acceleration: Running 10 analysis modules sequentially took ~20 minutes. By parallelizing independent LLM calls with Python's asyncio.gather, I brought the full report compilation time down to under 3 minutes.

Full-Stack Implementation

Agent Orchestration LangGraph, LangChain, Blackboard State Pattern
Backend API FastAPI (Async REST endpoints, rate limiting, Pydantic V2)
Frontend React 18, TypeScript, Vite, Tailwind CSS, shadcn/ui
Database & Checkpoints PostgreSQL, Supabase (Graph checkpointing, session management)
Deployment Docker, Docker Compose, uv package manager

Smart Healthcare Diagnosis System

Personal Project • PyTorch, Transformers

Trained and evaluated deep learning models for diagnostic medical imaging:

  • Brain Tumor Detection (MRI): Classifying intracranial lesions from preprocessed MRI scans using convolutional networks.
  • Chest X-Ray Pathology: Multi-label classification for common pulmonary conditions.
  • Achieved 94% classification accuracy on the held-out test split using standard data augmentation and transfer learning.

Text-to-3D Generation & Geospatial Search

Industry Role • AI 3D Scanning Solution (2025–Present)

Built production pipelines combining generative AI, vector retrieval, and geospatial filtering:

  • Text-to-3D Pipeline: Integrated open-source models to generate textured 3D meshes from user prompts and reference view angles.
  • Conversational RAG Assistant: Grounded user assistant built with LangChain and LangGraph for catalog search and question answering.
  • Geospatial Semantic Search: Stored Gemini embeddings in PostgreSQL with pgvector, filtering search results using the Haversine formula to return nearby locations matching natural language queries.
  • Microservice Backend: Asynchronous FastAPI service with SQLAlchemy ORM and containerized Docker orchestration.
