Research Overview

My research program addresses a foundational bottleneck in applied artificial intelligence: How do we engineer autonomous, multi-agent AI systems that execute reliably without degrading, losing state, or producing malformed outputs in production?

Core Research Pillars

Stateful Orchestration

Graph-based execution cycles, persistent checkpoints, and asynchronous scheduling to eliminate conversational context loss.

Self-Healing Reliability

Deterministic schema enforcement, automatic LLM repair loops, and grammar-constrained JSON generation.

Multimodal Intelligence

Generative text-to-3D pipelines and dense vector retrieval using Gemini embeddings + pgvector.

Validator-AI: Stateful Multi-Agent System

Featured Research Project • 2025–2026

Traditional conversational LLM architectures rely on linear, stateless request-response interaction loops. In complex multi-stage tasks—such as automated startup feasibility analysis—stateless interactions suffer from severe context collapse, erratic intermediate tool calls, and high vulnerability to transient system interruptions.

System Architecture & State Persistence

To solve this, Validator-AI was architected as a cyclic directed state graph using LangGraph backed by a durable PostgreSQL state checkpointer. Instead of transmitting raw conversation histories across prompts, execution state is treated as a versioned, durable database record:

  • Fault-Tolerant Resumption: If a network failure, rate limit, or node timeout occurs midway through a 7-step analysis, the workflow resumes exactly from the last committed checkpoint rather than re-running from scratch.
  • Asynchronous Acceleration: Independent verification agents (e.g., market size analyzer, competitive intelligence agent, unit-economic validator) were migrated from sequential execution to asyncio.gather, shrinking total wall-clock duration from ~20 minutes to under 3 minutes.

Self-Healing Schema Enforcement

A persistent vulnerability in LLM agent pipelines is schema malformation (missing JSON keys, malformed markdown fences, type violations). Validator-AI implements an automated self-healing step:

Self-Healing Mechanism: When a downstream node receives an output violating the expected Pydantic schema, the payload is caught by a deterministic validation filter and re-routed to a specialized repair agent along with the validation error traceback. In comprehensive unit tests, this mechanism caught and repaired 100% of defined schema error patterns without throwing uncaught exceptions.

Stress Testing & Concurrency Benchmarking

The system was evaluated through an extensive testing suite (Pytest, Playwright, Coverage.py) and load tested against up to 100 concurrent simulated founder sessions, documenting specific failure modes and resilience characteristics.

Smart Healthcare Diagnosis System

A deep learning clinical screening pipeline built with PyTorch and modern convolutional/transformer architectures for automated radiological assessment:

  • MRI Brain Tumor Detection: Trained on multi-sequence magnetic resonance imagery with targeted contrast normalization to localize intracranial neoplasms.
  • Chest Radiography Pathology: Multi-class chest X-ray classification for pulmonary anomalies (pneumonia, infiltration, effusion).
  • Benchmark Results: Achieved an aggregate 94% classification accuracy on the held-out evaluation test split with high sensitivity on critical anomaly detection.

Text-to-3D Generation & Geospatial Semantic Search

Developed during industry engineering work at AI 3D Scanning Solution, this pipeline addresses high-dimensional multimodal asset creation and localized semantic discovery:

  • Generative 3D Asset Synthesis: Integrated open-source diffusion models that convert natural language descriptions and multi-angle 2D reference images into textured 3D mesh representations.
  • Hybrid Spatial-Semantic Search: Engineered an async FastAPI microservice that computes dense embeddings via Google Gemini, stores vectors inside PostgreSQL pgvector, and calculates spherical distance filters using the Haversine formula to return semantically matched nearby entities in real time.
