Validator AI: Multi-Agent Startup Validation Platform

Bachelor's Capstone & Final Year Project • University of Sahiwal (2025–2026) • aliHasnainme/validator-ai

Validator AI was my undergraduate capstone project and bachelor's thesis. Thoroughly evaluating early-stage startup ideas requires analyzing multiple domains: market demand, financial viability, tech stack feasibility, competitors, and potential regulatory risks. Giving this entire task to a single LLM prompt leads to hallucinated data and shallow answers. Validator AI coordinates a team of specialized agents—each focused on one specific domain—to interview founders and compile a comprehensive validation report.

System Design & Architecture

  • Conversational Founder Interview: An interviewer agent asks clarifying questions to unpack the core thesis, target audience, and business model before analysis begins.
  • Live Web Research: A researcher agent queries the Tavily API to gather live market data, recent competitors, and industry benchmarks.
  • Stateful Graph (LangGraph): The orchestration is modeled as a stateful cyclic graph with a shared blackboard state.
  • State Checkpointing (PostgreSQL): Integrated database checkpointing so long-running evaluations can be paused, inspected, and resumed at any step without losing intermediate state.
  • Self-Healing Output Parser: Engineered a progressive recovery fallback parser (strict schema parsing → regex JSON block extraction → brace balance repair → syntax correction) that fixes malformed LLM responses on the fly without crashing the pipeline.
  • Asynchronous Acceleration: Running 10 analysis modules sequentially took ~20 minutes. By parallelizing independent LLM calls with Python's asyncio.gather, total report compilation time was reduced to under 3 minutes.
  • Full-Stack Architecture: Built an async FastAPI backend containerized with Docker, paired with a modern React 18 + TypeScript frontend styled with Tailwind CSS.

Local Mart — Hyperlocal AI Commerce & Semantic Search

Open Source • FastAPI, Flutter, pgvector, Gemini • aliHasnainme/local-mart

An AI-powered hyperlocal commerce platform connecting local buyers with neighborhood merchants:

  • Semantic Product Search: Generated dense vector embeddings using Google Gemini models, indexed in PostgreSQL using pgvector for natural language product discovery.
  • Haversine Geospatial Filtering: Combined vector similarity with SQL-level Haversine distance calculations to return listings within user-specified physical distance radiuses.
  • Multimodal Tagging: Utilized Gemini Vision for automated product categorization, image tagging, and description generation from merchant photos.
  • Mobile & API Stack: Cross-platform Flutter mobile application backed by an asynchronous FastAPI backend service.
