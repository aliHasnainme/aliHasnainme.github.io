Research & Projects

My primary research focuses on making multi-agent LLM systems reliable and practical. In complex tasks requiring many conversational turns or asynchronous steps, models often suffer from lost state, erratic execution, and malformed outputs. Below are details of the projects I have developed to address these problems.

Validator AI: Multi-Agent Startup Validation Platform

Bachelor's Final Year Project (FYP) • University of Sahiwal (2025–2026) • aliHasnainme/validator-ai

Validator AI was my undergraduate capstone project and bachelor's thesis. It is an end-to-end autonomous multi-agent platform designed to interview startup founders, conduct automated real-time web research, execute deep strategic analysis across up to 10 specialized dimensions, and synthesize investor-grade reports with viability scoring.

The 6-Stage Multi-Agent Pipeline

  1. Interview Phase: An adaptive interviewer agent asks 1–5 targeted clarifying questions to understand the founder's thesis.
  2. Research Phase: Automated web research via the Tavily API gathers live market data, trends, and existing competitor footprints.
  3. Parallel Analysis: Concurrent execution of up to 10 specialized analysis modules:
    • Market Analysis • Financial Projections • Tech Stack Architecture • Competitor Landscape
    • Business Model Canvas (BMC) • Regulatory Compliance • Go-to-Market (GTM) Strategy
    • Risk Analysis • Product Roadmap • Funding Strategy
  4. Compilation: A specialized Compiler agent cross-examines outputs across all modules to catch and reconcile contradictions (e.g. market assumptions vs. financial projections).
  5. Quality Assurance: Consistency cascades detect and auto-correct cross-module discrepancies.
  6. Delivery: Investor-grade HTML and JSON reports with 5-dimension and 8-dimension viability scoring and actionable Go/No-Go recommendations.

System Architecture & State Persistence

  • Stateful Graph (LangGraph): The entire agent lifecycle is modeled as a cyclic state machine with a shared Blackboard state (ValidationState).
  • Interrupt & Resume via Checkpointing: Built with PostgreSQL / MemorySaver checkpointing, allowing users to pause workflows, review intermediate outputs, upgrade tiers, and resume without losing session state.
  • Self-Healing Output Recovery: A multi-stage recovery pipeline for structured LLM parsing (Pydantic structured output → regex extraction → brace matching → syntax repair).
  • Asynchronous Acceleration: Parallelized module execution using Python's asyncio.gather (up to 15 concurrent LLM calls), reducing total report generation time from ~20 minutes to under 3 minutes.

Full-Stack Implementation

Agent Orchestration LangGraph, LangChain, Blackboard State Pattern
Backend API FastAPI (Async REST API, rate limiting, Pydantic V2)
Frontend React 18, TypeScript, Vite, Tailwind CSS, shadcn/ui
Database & Storage Supabase, PostgreSQL (Graph checkpointing, session management)
Deployment Docker, Docker Compose, uv package manager

Smart Healthcare Diagnosis System

Personal Project • PyTorch, Transformers

Trained deep learning classification models for radiographic analysis:

  • MRI Brain Tumor Detection: Localizing intracranial lesions using preprocessed magnetic resonance imaging sequences.
  • Chest X-Ray Pathology: Multi-class classification of pulmonary conditions on radiographic images.
  • Achieved 94% classification accuracy on the held-out test split.

Text-to-3D Generation & Geospatial Search

Engineering Role • AI 3D Scanning Solution (2025–Present)

Developed production AI pipelines combining generative modeling and spatial retrieval:

  • 3D Generation: Pipeline using open-source models to generate textured 3D assets from an input image prompt and reference views.
  • Conversational RAG: Grounded user dialogue assistant using LangChain and LangGraph for context retrieval.
  • Spatial Semantic Search: Integrated Google Gemini embeddings stored in PostgreSQL pgvector, filtering search results using the Haversine formula to return nearby items matching semantic queries.
  • Backend Service: Asynchronous FastAPI service with SQLAlchemy ORM and containerized Docker orchestration.
