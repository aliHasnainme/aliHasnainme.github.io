Evaluation Data & Benchmarks

Test sets and evaluation cases created while benchmarking multi-agent coordination, graph checkpointing, and LLM schema recovery routines.

Startup Evaluation Test Suite (SVB-100)
Multi-Agent Workflow Evaluation JSON Lines

A collection of 100 early-stage startup scenarios across fintech, healthcare, SaaS, and marketplaces. Built to benchmark multi-agent pipeline consistency: testing whether parallel agents extract consistent value propositions, reasonable TAM market figures, and coherent unit economic estimates without hallucinating conflicting data.

GitHub / Repository Project Architecture
Schema Recovery Test Corpus (SR-1000)
LLM Reliability Malformed JSON Error Recovery

A set of 1,000 real-world and synthetic malformed LLM responses collected during development: missing closing brackets, conversational markdown preamble, escaped quotes in JSON strings, and truncated keys. Used to test the accuracy and speed of automated parser recovery fallbacks.
