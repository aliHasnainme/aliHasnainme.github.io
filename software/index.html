validator-core: Stateful LangGraph Engine with PostgreSQL Checkpointing
Python LangGraph PostgreSQL Asyncio

A modular Python framework implementing stateful, fault-tolerant multi-agent loops. Features a drop-in PostgreSQL state checkpointer allowing long-horizon LLM workflows to survive process interruptions, alongside an automated repair loop for malformed Pydantic payloads.

geo-vector-service: Hybrid Spatial-Semantic Retrieval API
FastAPI pgvector Gemini Embeddings Docker

An asynchronous FastAPI microservice combining dense neural semantic search with exact spherical geospatial distance computation using Haversine formulations in PostgreSQL. Allows querying entities matching both conceptual natural language semantics and proximity radius.

med-vision-classifier: Diagnostic Classification Suite for Radiology
PyTorch Torchvision Vision Transformers Medical Imaging

A clean PyTorch pipeline for multi-label radiographic classification on MRI and chest X-ray datasets. Includes preprocessing utilities, adaptive data augmentation, and benchmark evaluation scripts achieving 94% test accuracy.
