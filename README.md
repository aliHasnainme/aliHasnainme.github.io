# Ali Hasnain &mdash; Academic Website

Personal academic portfolio website of **Ali Hasnain**, Software Engineering graduate from the University of Sahiwal, aspiring AI researcher, and Python developer. Built with clean, minimalist academic design incorporating the **Hugo Docsy** layout system, responsive sidebar navigation, project showcases, and client-side instant search.

---

## 📁 Directory Structure

```text
academic-website/
├── index.html                                  # Homepage (Bio, broad AI interests, selected projects, updates)
├── research/
│   └── index.html                              # Projects & Systems (Validator AI, 3D pipelines, Local Mart, etc.)
├── pubs/
│   └── index.html                              # Publications & scholarly profiles
├── bio_and_cv/
│   └── index.html                              # Biography, curriculum vitae, education, experience, skills
├── contact/
│   └── index.html                              # Contact coordinates, graduate research inquiries
└── assets/
    ├── css/
    │   └── docsy-custom.css                    # Docsy-style styling, responsive grid, typography
    ├── images/
    │   ├── Profile.jpeg                        # Profile headshot
    │   └── profile.svg                         # Fallback avatar
    └── js/
        ├── search-data.js                      # Search index for site pages and projects
        └── main.js                             # Auto Table-of-Contents, search modal, mobile toggle
```

---

## 🚀 How to View Locally

Simply open `index.html` in your web browser:
- Double-click on `index.html`, OR
- Right-click &rarr; **Open With** &rarr; Your preferred browser.

No build tools, compilation, or external package managers required. Everything runs out of the box with standards-compliant HTML5, CSS3, and modern JavaScript.
