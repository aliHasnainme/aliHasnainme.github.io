Validator-AI: A Stateful, Fault-Tolerant Multi-Agent Framework for Complex Decision Workflows
Ali Hasnain
Targeting Peer-Reviewed Conference / Journal in Applied AI & Software Engineering (2026/2027)

Abstract: Multi-agent systems powered by Large Language Models (LLMs) frequently break in multi-step analytical domains due to stateless session loss, unbounded context growth, and schema malformation. In this paper, we present Validator-AI, a cyclic state-graph architecture built upon LangGraph and backed by a transactional PostgreSQL checkpointing engine. By separating volatile LLM execution from persistent workflow states, the system guarantees seamless resumption after network failures, timeouts, and rate limits. Furthermore, we introduce an automated self-healing validation layer that deterministically routes malformed outputs through a structured repair loop, neutralizing 100% of defined schema error patterns in our test harness. Re-architecting independent validation modules with asynchronous concurrent scheduling reduced end-to-end latency from ~20 minutes to under 3 minutes under load testing with up to 100 concurrent agents.

Preprint in Progress
Deterministic Output Recovery in Autonomous LLM Pipelines: Mitigating Schema Drift and State Degeneracy
Ali Hasnain
Technical Report / Working Draft • University of Sahiwal

Abstract: Structured JSON extraction from frontier LLMs is known to produce intermittent formatting anomalies under heavy cognitive load. This study benchmarked retry-based prompting strategies against deterministic schema repair filters across over 1,000 synthetic malformed responses. Our findings show that deterministic repair cycles with structured error context reduce token consumption by 48% compared to brute-force prompting retries while maintaining 100% adherence to target Pydantic contracts.
