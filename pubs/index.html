Working Papers & Preprints in Preparation

Stateful Multi-Agent Workflows: Checkpointing, Parallelism, and Schema Recovery in Long-Horizon Task Execution
Ali Hasnain — Drafting manuscript for submission

Drawing on empirical findings from the Validator AI project, this paper examines failure modes in long-horizon multi-agent workflows—particularly session context loss during interruptions and downstream schema parsing failures. It evaluates state persistence using database checkpointing, parallel execution with asyncio, and progressive JSON recovery fallbacks against standard sequential retry strategies.
