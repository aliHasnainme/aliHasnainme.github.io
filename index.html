Ali Hasnain

Software Engineering Graduate • AI Developer & Researcher

I recently completed my BS in Software Engineering at the University of Sahiwal, Pakistan (CGPA 3.63/4.00). My research interests are in machine learning and artificial intelligence, with a specific interest in multi-agent LLM systems, generative models, and building AI systems that remain reliable in practice—such as handling state loss, malformed outputs, and execution errors.

Alongside academic research, I have worked professionally as a Python developer at AI 3D Scanning Solution and Medtronix Systems, building text-to-3D pipelines, RAG systems with LangChain and LangGraph, semantic vector search services using pgvector and Gemini embeddings, and asynchronous FastAPI microservices.

I am currently preparing research manuscripts based on my work in stateful agent validation and seeking graduate study (MS/PhD) opportunities in computer science and AI.

Research Interests

  • Multi-Agent LLM Architectures: Cyclic execution graphs, state persistence, and checkpointing for long-running workflows.
  • Reliable AI & Output Conformance: Handling schema drift, self-healing recovery loops for malformed JSON, and deterministic error handling in LLM pipelines.
  • Retrieval & Search: Dense vector retrieval, hybrid semantic-geospatial search (pgvector + Haversine filtering), and conversational RAG.
  • Computer Vision & Generative AI: Text-to-3D asset pipelines, diffusion models, and diagnostic medical image classification.

Bachelor's Final Year Project

Validator AI — Multi-Agent Startup Validation Platform
Ali Hasnain — Final Year Project (FYP) • University of Sahiwal (2025–2026)

My undergraduate capstone project and thesis: an end-to-end multi-agent platform that interviews founders, executes automated market research via Tavily API, and generates investor-grade strategic reports using specialized LLM agents orchestrated by LangGraph.

  • LangGraph Workflow: Modeled as a stateful directed graph with a shared Blackboard state (ValidationState) and PostgreSQL checkpointer supporting interrupt & resume across sessions.
  • Parallel Analysis Modules: Executes up to 10 specialized analysis modules concurrently (Market, Financials, Tech Stack, Competitors, Business Model Canvas, Regulatory, Go-to-Market, Risk, Roadmap, Funding Strategy).
  • Self-Healing Pipeline: A Compiler agent detects and auto-corrects cross-module contradictions with multi-stage JSON recovery fallback (structured output → regex → brace matching → syntax repair).
  • Full-Stack Architecture: Async FastAPI backend with rate limiting, containerized with Docker, paired with a React 18 + TypeScript + Vite frontend styled with Tailwind CSS and Supabase authentication.
