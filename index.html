Ali Hasnain

Software Engineering Graduate • AI Developer & Researcher

Hi, I'm Ali. I recently graduated with a BS in Software Engineering from the University of Sahiwal, Pakistan (CGPA 3.63 / 4.00). My main focus is on artificial intelligence and machine learning, with a strong interest in multi-agent systems, generative models, and making LLM pipelines reliable enough for real-world production.

Much of my recent work focuses on solving the practical problems that arise when building complex agent workflows: keeping track of session state across multi-turn conversations, handling schema mismatches and broken JSON outputs gracefully, and optimizing latency across distributed calls.

Alongside my studies, I have worked as a Python developer at AI 3D Scanning Solution and Medtronix Systems. In those roles, I built text-to-3D asset pipelines, conversational RAG assistants using LangChain and LangGraph, semantic vector search services using pgvector and Gemini embeddings, and asynchronous FastAPI microservices.

I am currently writing up a research paper based on my final year capstone project (Validator AI) and preparing applications for MS/PhD programs in Computer Science and AI.

Research Interests

  • Multi-Agent Systems & State Persistence: Coordinating specialized agents in cyclic graphs (LangGraph) with database checkpointing so workflows can be paused, inspected, and resumed without losing state.
  • Reliable LLM Pipelines: Building deterministic fallback layers to catch and repair schema deviations, malformed JSON, and logical contradictions across multi-agent reasoning steps.
  • Semantic Search & Retrieval (RAG): Combining dense vector search (pgvector, Gemini embeddings) with geospatial filtering (Haversine distance) to build grounded, context-rich retrieval systems.
  • Generative AI & Vision: Text-to-3D asset generation, diffusion models, and diagnostic deep learning models for medical image classification.

Bachelor's Final Year Project

Validator AI — Multi-Agent Startup Validation Platform
Ali Hasnain — Final Year Project & Thesis • University of Sahiwal (2025–2026)

For my undergraduate capstone project and thesis, I wanted to see how autonomous LLM agents could tackle complex analytical work that usually takes days of manual effort. Validator AI interviews founders, performs live market research via Tavily, and coordinates 10 specialized agent modules to generate thorough startup validation reports.

  • LangGraph Workflow: Modeled as a stateful cyclic graph with a shared blackboard state (ValidationState). Uses a PostgreSQL checkpointer so users can pause an evaluation, review intermediate findings, and resume seamlessly.
  • Parallel Execution: Ran independent analysis modules concurrently using Python's asyncio.gather (handling up to 15 concurrent LLM calls), bringing total report generation time down from ~20 minutes to under 3 minutes.
  • Self-Healing Output Parser: Engineered a progressive fallback parser (structured output → regex extraction → brace matching → syntax repair) that fixes broken JSON responses on the fly instead of crashing the pipeline.
  • Full-Stack Architecture: Built an async FastAPI backend containerized with Docker, paired with a React 18 + TypeScript + Vite frontend styled with Tailwind CSS.
